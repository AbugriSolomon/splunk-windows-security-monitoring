# Windows Security Monitoring with Splunk

## Project Overview
This project documents a hands-on cybersecurity lab focused on Windows security monitoring and log analysis using Splunk.

The objective is to practice collecting, searching, and analyzing Windows security events while developing foundational SOC analyst skills.

## Objectives
- Understand Windows security event logs.
- Configure Splunk to monitor security-related data.
- Practice searching and analyzing logs using SPL.
- Identify and interpret relevant security events.
- Document findings and investigation processes.

## Tools and Technologies
- Splunk Enterprise
- Microsoft Windows
- Windows Event Logs
- Search Processing Language (SPL)

## Lab Environment
- Operating System: Windows
- SIEM: Splunk Enterprise
- Data Source: Windows Event Logs

## Project Activities
- Splunk installation and configuration
- Windows event log collection
- Log analysis and search
- Security event investigation
- Documentation of observations
